# Student Performance Analyzer 📊

A beginner-friendly Data Science project that analyzes student academic performance using Python.

## 📌 Project Overview

The **Student Performance Analyzer** analyzes academic factors such as attendance, study hours, assignment scores, internal marks, and final marks to understand overall student performance.

The project uses data analysis and visualization techniques to identify performance patterns and relationships between different academic factors.

## 🎯 Objectives

* Analyze student academic data
* Calculate statistical measures such as average, highest, and lowest marks
* Classify students based on their final marks
* Calculate the overall pass percentage
* Visualize student performance
* Analyze correlations between academic factors

## 📊 Dataset

The dataset contains the following attributes:

| Attribute        | Description                |
| ---------------- | -------------------------- |
| Student_ID       | Unique student identifier  |
| Gender           | Student gender             |
| Attendance       | Attendance percentage      |
| Study_Hours      | Average study hours        |
| Assignment_Score | Assignment marks           |
| Internal_Marks   | Internal examination marks |
| Final_Marks      | Final examination marks    |

## 🔍 Analysis Performed

The project performs:

1. Dataset loading and inspection
2. Statistical analysis
3. Student performance classification
4. Pass percentage calculation
5. Performance distribution analysis
6. Data visualization
7. Correlation analysis
